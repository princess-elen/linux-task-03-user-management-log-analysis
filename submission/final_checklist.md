# Final submission checklist

- [ ] `commands_used.txt` reflects the commands actually executed.
- [ ] Screenshot evidence is genuine, readable, and named clearly.
- [ ] `reports/error_report.txt` contains the ERROR grep output.
- [ ] `reports/activity_report.md` is completed.
- [ ] `reports/observations.md` records the actual ownership/access test.
- [ ] `docs/explanations.md` includes the required explanations of grep, chown, and usermod.
- [ ] `evidence/verification/` contains the collected verification text.
- [ ] No passwords or secrets are included.
