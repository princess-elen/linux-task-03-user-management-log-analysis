# Submission guide

Before submitting, check that the repository contains:
- the exact commands you actually executed in `submission/commands_used.txt`;
- real screenshots showing the key terminal results;
- the generated `error_report.txt`;
- completed activity and observation reports;
- evidence verification text files.

Do not submit placeholder screenshots or claim a command succeeded unless you observed its output. Redact passwords, tokens, private hostnames, and unrelated personal information from screenshots.
